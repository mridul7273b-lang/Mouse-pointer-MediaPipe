# Mouse-pointer-MediaPipe
Computer Vision with OpenCV is like printing 'hello world' in a new language. Creating a touch-free mouse requires building a strong vision pipeline. My latest project uses OpenCV to create a Mouse Controller with pinch detection using cv2, mediapipe, and pyautogui.
